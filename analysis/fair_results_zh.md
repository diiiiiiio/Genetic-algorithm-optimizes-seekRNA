# 公平对照结果

正式运行在试跑计时之后锁定，种子和预算没有按结果再改。记录在 `analysis/fair_protocol_lock.json`。原始五张 CSV 没有覆盖。

共同起点是 `initial_candidates.csv` 的 11 条，用 RNAfold 重算后与表中分数的最大差为 `4.44e-16`。起点最好分 **3.433253**。参考序列和两个方法都用这一套 RNAfold 评分；`Phy_mark` 的权重没有改。每个方法、每个种子有 7500 次“首次完整评分”，失败也计入。重复序列不再占额度。

可累计随机搜索从全部已通过评分的候选里均匀抽父代，用同一套突变，没有交叉，编辑可以叠加上去。遗传算法保留原来的按分选父代和交叉。

20 个正式种子全部用满额度。总耗时 3551 秒。223499 次评分成功，76501 次失败。

## 主要结果

每个种子的指标是：额度用完时的最好分，减去共同起点的最好分。

| | 提升的最小 / 平均 / 最大 |
|---|---|
| 遗传算法 | 0.1834 / 0.1893 / 0.1998 |
| 可累计随机搜索 | 0.1370 / 0.1525 / 0.1799 |
| 遗传算法减随机搜索 | 0.0085 / 0.0368 / 0.0628 |

20 个种子里遗传算法的提升都更高。配对差的平均是 **0.0368**，按种子重抽样的 95% 区间是 **0.0295 到 0.0435**。

遗传算法最好候选的编辑深度平均 14.8，随机搜索平均 4.9。随机搜索确实能连续改，只是高分谱系改得更浅。

## 长度

送去评分并成功的候选里，长度和分数的秩相关是遗传算法 -0.21、随机搜索 -0.18。在这批候选里，更长没有对应更高分。

遗传算法的最好候选长度是 126–136，随机搜索是 136–148。起点是 142。两种方法都评过的长度上，按该长度最大分之差、再按较小样本数加权，20 个种子的平均差是 **0.0608**（95% 区间 0.0574 到 0.0643）。同长度之后，遗传算法仍然更高。
